# Google Search Console

The site is prepared for indexing with:

- `public/robots.txt`
- `public/sitemap.xml`
- Canonical URL metadata
- Open Graph metadata

## Submit the site

1. Open Google Search Console.
2. Add the URL-prefix property `https://daakye.online`.
3. Complete ownership verification using the HTML tag or DNS method Google provides.
4. Open **Sitemaps**, enter `sitemap.xml`, and submit it.
5. Use **URL Inspection** for `https://daakye.online/` and select **Request indexing**.

No verification token is stored in the project because it is unique to the Google account and property owner.
